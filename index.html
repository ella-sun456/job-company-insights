它在做什么

你把目标岗位的 JD 发过来（截图 / 链接 / 文字都行），再给个公司名，它先做真实调研，再输出一份单文件、双 Tab 的 HTML 全景报告——左边拆岗位与你的匹配度，右边把这家公司从工商信息一直讲到商业模式、竞品和隐藏需求。

你会得到什么

资深 HR 视角五问这个岗位到底在干什么？在业务里补哪条链路？要准备什么案例？
JD 逐条解码 + 人才画像卡每一句要求背后的真实意图是什么？他们真正想招的是「哪种人」？
匹配度百分制 + Gap 清单四个维度各差多少？面试第一段话怎么说？两周内必须补哪些坑？
公司基本面 + 商业模式 + 竞品它靠什么赚钱？这个岗位所在业务线是主战场还是边缘业务？
隐藏需求与岗位差异JD 没写但八成在乎的是什么？面试时可以反问哪三个问题？
面经与行动指南会考什么、前一天做什么、当天带什么？

报告长什么样（真实截图）

三条不会破的底线：优先一手来源、查不到就写「无法确认」，不编数字；JD 明确标蓝、合理推测标黄；有简历才打分，没简历不硬凑匹配度。

怎么用

装好后直接说话就行：

用 job-company-insights 分析这个 JD：[粘贴 JD 文字 / 截图 / 链接]，公司：某某科技

想算匹配度就把简历一起发上来；只发 JD 也可以，它会先拆岗位、再问你补不补简历。生成的是完整 HTML，浏览器打开即看，页面右下角有「⤓ 保存 / 下载 HTML」按钮。

点击 GitHub 仓库 查看源码与安装包 · Demo 中的「星澜宠物」为化名，数据均为演示虚构，版式与真实输出一致。
