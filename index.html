What it does它在做什么

Send the target JD (screenshot, link or plain text is fine) plus a company name. It researches first, then returns a single-file, two-tab HTML report — the left tab decodes the role and your fit, the right tab covers the company from registration data through business model, competitors and unstated needs.你把目标岗位的 JD 发过来（截图 / 链接 / 文字都行），再给个公司名，它先做真实调研，再输出一份单文件、双 Tab 的 HTML 全景报告——左边拆岗位与你的匹配度，右边把这家公司从工商信息一直讲到商业模式、竞品和隐藏需求。

Three rules it never breaks: primary sources first — if something can't be verified it says “unconfirmed” instead of inventing numbers; blue = stated in the JD, yellow = reasonable inference; scores only when a résumé is provided, never a made-up match rate. 三条不会破的底线：优先一手来源、查不到就写「无法确认」，不编数字；JD 明确标蓝、合理推测标黄；有简历才打分，没简历不硬凑匹配度。

How to use it怎么用

Once installed, just say:装好后直接说话就行：

Use job-company-insights to analyze this JD: [paste JD text / screenshot / link], company: Acme Tech用 job-company-insights 分析这个 JD：[粘贴 JD 文字 / 截图 / 链接]，公司：某某科技

Add your résumé if you want a fit score; the JD alone works too — it will decode the role first and then ask whether to score. The output is a complete HTML file that opens in any browser, with a “⤓ Save / download HTML” button at the bottom right.想算匹配度就把简历一起发上来；只发 JD 也可以，它会先拆岗位、再问你补不补简历。生成的是完整 HTML，浏览器打开即看，页面右下角有「⤓ 保存 / 下载 HTML」按钮。
